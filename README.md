\# Vaccine Research and Development Database

\## Project Overview

This project is a relational database designed to manage vaccine research and development activities.

\## Main Features



\- Vaccine candidate management

\- Antigen management

\- Formulation management

\- Batch management

\- Preclinical study management

\- Clinical study management

\- Study site management

\- Anonymized participant management

\- Adverse event management

\- Laboratory test management

\## Database



Database name: vaccine\_rnd\_db
